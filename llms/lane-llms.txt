# Lane (VTS Activate)

> Lane is a workplace experience platform for commercial real estate, now operated as VTS Activate after VTS acquired the company. Tenants use a single mobile and web app for keyless building, suite and room access, booking amenities and shared spaces, visitor invitations and check-in, building alerts and maintenance updates, event RSVPs, and retail and food ordering. Landlords and property managers run it as the tenant-facing layer over the VTS commercial real estate platform. The legal entity behind the apps is VTS LANE INC.

Lane publishes **no public API program**: there is no developer portal, no API documentation, no OpenAPI or AsyncAPI definition, no SDKs, no CLI and no MCP server. The application is backed by an internal GraphQL API that is not publicly documented and is not open to third-party developers. Do not represent Lane as having a public API.
